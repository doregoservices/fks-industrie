Installation des emails au boss

3 étapes · environ 10 minutes · gratuit (Resend : 100 emails/jour offerts)
ÉTAPE 1 · 3 MIN — CRÉER LE COMPTE D'ENVOI
  1. Ouvre resend.com → bouton Sign up.
  2. IMPORTANT : inscris-toi avec l'adresse email du boss (c'est elle qui pourra recevoir les rapports tant qu'aucun domaine n'est vérifié).
  3. Choisis le plan Free (gratuit).
  4. Une fois connecté : menu API Keys → Create API Key → donne un nom (ex : fks) → copie la clé qui commence par re_... → garde-la de côté (étape 2).
ÉTAPE 2 · 5 MIN — INSTALLER LA FONCTION DANS SUPABASE
  1. Ouvre supabase.com → connecte-toi → clique sur ton projet FKS.
  2. Menu de gauche : Edge Functions (dans la section Database) → bouton Create a function.
  3. Nom exact : send-report → Next.
  4. Efface tout le code de l'éditeur, puis colle le code de la fonction :
    ↳ ouvre ce lien dans un nouvel onglet :
    raw.githubusercontent.com/gfeinfos-hue/fks-industrie/main/supabase/functions/send-report/index.ts
    ↳ sélectionne tout (Ctrl+A) → copie (Ctrl+C) → colle dans l'éditeur Supabase (Ctrl+V).
  5. Clique Deploy (ou Save). La fonction est installée.
Puis les 3 codes secrets — sur la page de la fonction, onglet Secrets → Add secret (3 fois) :

RESEND_API_KEYta clé re_... de l'étape 1

EMAIL_FROMFKS Industrie <onboarding@resend.dev>
ÉTAPE 3 · 1 MIN — BRANCHER DANS L'APPLICATION
  1. Ouvre l'application → Réglages → descends à 📧 Envoi des rapports au boss.
  2. Email du boss : l'adresse du boss.
  3. Clé d'envoi (REPORT_KEY) : VOTRE-REPORT-KEY (exactement la même que dans Supabase).
  4. Enregistrer → Envoyer un email de test → le boss reçoit un email « ✅ Si vous lisez cet email… » 🎉
SI ÇA NE MARCHE PAS
Message dans l'appSolution
« fonction NON DÉPLOYÉE »le nom n'est pas exactement send-report → supprime et recrée
« REPORT_KEY invalide »le mot de passe diffère entre Supabase (Secrets) et Réglages → remets VOTRE-REPORT-KEY des deux côtés
« Resend: ... only send testing emails to your own address »le compte Resend n'a pas été créé avec l'email du boss → recrée Resend avec l'email du boss (ou fais vérifier ton domaine par Resend)
« RESEND_API_KEY non configuré »le secret RESEND_API_KEY manque ou la clé est fausse dans Supabase → Secrets
